# Jumpoodle

## Installation Instructions

1. Clone the repo
```sh
git clone https://github.com/syioa/jumpoodle.git
```

2. And just open `index.html` in a web browser or serve it via your local server.

**PS**: there are no dependencies to install.


## How to Play

- Move left or right with `a`/`ArrowLeft` or `d`/`ArrowRight` respectively.
- You can move through the left edge and come out from the right and vice versa.
- When you lose press `space` to restart.
